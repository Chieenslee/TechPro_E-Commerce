[GROUP OF SHAPES/DIAGRAM]
Users
Id PK, Name, Email UNIQUE, Role (Admin|Customer), Status (Active|Suspended), CreatedAt, LastLoginAt
Products + ProductTags
Price, OriginalPrice, Rating 0-5, Sku UNIQUE, Image, IsNew, OnSale · Tags (ProductId, Tag) 
PK composite
Orders + OrderItems
OrderNumber PK, UserId FK, Customer*, address fields, Subtotal/Shipping/Discount/Total, 
Status CHECK
OrderItems: ProductId FK nullable, Name, Price, Qty, Image snapshot — CASCADE delete
ProductReviews
ProductId, UserId FK, Author, Rating 1-5, Comment, CreatedAt
Addresses
UserId FK CASCADE, Label, Recipient, Phone, Line1, City, IsDefault
WishlistItems
PK (UserId, ProductId) — CASCADE both sides
NewsletterSubscribers
Email UNIQUE, Status Active|Unsubscribed
Indexes & Constraints (CI validated)
IX_Products_Category · IX_Orders_CustomerEmail · IX_Orders_Status_CreatedAt DESC
IX_ProductReviews_ProductId_CreatedAt · IX_Addresses_UserId
CHECK: CK_Users_Role, CK_Users_Status, CK_Products_Price>0, CK_Products_Rating, CK_Orders_Status, CK_OrderItems_Qty>0
seed.sql: INSERT Products, Users mẫu — CI grep đảm bảo tồn tại
import-json-data.ps1: merge JSON → SQL (NewsletterSubscribers, OrderItems referenced in CI)

run-all.ps1 — từng bước
1. Test-CommandExists sqlcmd · Invoke-Sql SELECT @@SERVERNAME
2. IF DB_ID('TechPro') IS NULL → CREATE DATABASE TechPro
3. IF OBJECT_ID Products missing → sqlcmd -i database/schema.sql · set ImportData
4. -ImportData → import-json-data.ps1 -ConnectionString ... -DataDirectory backend/Data
5. Stop-PortOwner 7099, 5016, 5173 (unless -KeepExisting)
6. Start-Process dotnet run --urls https://localhost:7099;http://localhost:5016
7. Start-Process pnpm dev --host localhost --port 5173 · sleep 4 · in PID
Ma trận kiểm thử
CI tự động: ESLint · Vite build · dotnet Release build · SQL grep + PS1 parse
Thủ công API: backend.http · Swagger/OpenAPI dev · Postman/curl
Thủ công UI: Vite HMR · flows mua hàng · admin status update
Chưa có: xUnit/NUnit · Playwright/Cypress · load test · security scan
stop-all.ps1: kill processes on ports · run-all.bat / stop-all.bat wrappers
Production checklist
Deploy artifact techpro-release từ GitHub Actions
Host FE: nginx/IIS static · BE: Kestrel service · SQL: Azure SQL / on-prem
Cập nhật CORS: production domain thay localhost:5173
Thay mock_token_123 bằng JWT + refresh token
HTTPS cert · secrets trong appsettings.Production.json / KeyVault
Logging: Serilog · health checks /health · monitoring
FE :5173 · BE :7099/:5016 · DB localhost/TechPro
